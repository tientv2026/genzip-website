## Quick add

Right-click files or folders → **GenZip → Add to "Name.zip"** or **Add to "Name.7z"**. Done, no dialog.

## Using the Create dialog

1. Click **Add** (or right-click → **Add to archive…**).
2. Set the name and destination folder.
3. Choose a format:
   - **ZIP** — opens everywhere.
   - **7Z** — smaller, can encrypt file names.
   - **TAR** — bundles files, common on Linux/macOS.
4. Pick a preset: **Normal**, **Maximum**, **Fast** or **Store** (no compression).
5. Click **Create**.

![Create dialog](/screenshots/create-en-light.png)

## Advanced

- **Compression level** and **method**.
- **Dictionary size** and **Solid** (7z only).
- **Split to volumes** in KB/MB/GB.

<div class="callout callout-note">GenZip does not create RAR files. RAR is proprietary; GenZip only reads and extracts it.</div>
