## Quick add

Right-click files or folders → **GenZip → Add to "Name.zip"** or **Add to "Name.7z"** to compress them without opening a dialog.

## Using the Create dialog

1. Click **Add** (or right-click → **Add to archive…**).
2. Set the name and destination folder.
3. Choose a format:
   - **ZIP** — a common format for sharing files.
   - **7Z** — supports file name encryption.
   - **TAR** — bundles files, common on Linux/macOS.
4. Pick a preset: **Normal**, **Maximum**, **Fast** or **Store** (no compression).
5. Click **Create**.

## Advanced

- **Compression level** and **method**.
- **Dictionary size** and **Solid** (7z only).
- **Split to volumes** in KB/MB/GB, useful for sending by email or copying to a USB drive.

<div class="callout callout-note"><strong>About RAR</strong>GenZip does not create RAR files. RAR is proprietary; GenZip only reads and extracts it.</div>
