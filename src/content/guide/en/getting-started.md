## Pick a build

| Build | Best for |
|---|---|
| **Microsoft Store** | Most people — automatic updates, signed by Microsoft. |
| **Installer .exe** | Installs for the current user, no admin rights needed. |
| **Portable .zip** | Runs from a USB stick or any folder, no right-click menu. |

## First run

1. Open GenZip from the Start menu.
2. Read and accept the **Terms of use** (asked once).
3. The **Home** screen appears: drop an archive on it, or click **Create archive** / **Open archive…**.

## Turn on the right-click menu

Go to **Settings… → Integration**, enable the GenZip context menu and click **Apply**.

<div class="callout">The portable build does not write to the registry, so it has no right-click menu.</div>
