## Open an archive

- Double-click it (once GenZip is associated with the format).
- Drag it onto the GenZip window.
- Click **Open archive…** on Home or in the **File** menu.

GenZip opens ZIP, 7z, RAR4/RAR5, TAR, GZ, BZ2, XZ, ZST, ISO, CAB, WIM and split archives such as `.7z.001`. If a part is missing, GenZip tells you which one.

## Browse and search

- Double-click a folder to enter it; use **Back / Forward / Up** next to the address bar.
- Type in the search box to filter by name.
- In the sidebar, **CONTENTS** filters by type: Folders, Documents, Images, Video, Audio, Other.
- Click a column header to sort.

## Select multiple items

Hold **Ctrl** to pick items, **Shift** to pick a range. The status bar shows how many are selected.

## Open a file inside

Double-click a file to open it with its default app. For executable files (exe, scripts…), GenZip asks before opening it.
