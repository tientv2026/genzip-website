## Open and apply settings

Open **Settings…** from the toolbar or the **Options** menu. Changes take effect when you click **Apply** or **OK**; **Reset to defaults** restores the original settings.

## Settings pages

| Page | Options |
|---|---|
| **General** | Language, recent files history |
| **Appearance** | Light / Dark / System, 9 accent colors, table columns |
| **Integration** | Right-click menu, file associations |
| **Compression** | Default format and level |
| **Extraction** | Destination, default handling of existing files |
| **Security** | Mark-of-the-Web, warnings for executable files |
| **Updates** | Automatic update checks, Stable/Beta channel |
| **Advanced** | Compression threads, temp folder |
