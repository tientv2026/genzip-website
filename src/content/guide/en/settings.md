## Open settings

Choose **Options → Settings…** to open the separate Settings window.

## Settings pages

| Page | Options |
|---|---|
| **General** | Language; recent files history and item count; clear history; list view style; visible columns |
| **Integration** | Shows **Managed by Windows for the Microsoft Store build**; file associations and the right-click menu are included in the package |
| **Compression** | Default format, level 0–9 and method |
| **Extraction** | Destination next to the archive, a fixed folder or ask; existing file handling; open the folder after extraction |
| **Security** | Preserve Mark of the Web and safety limits |
| **Appearance** | System / Light / Dark; accent color; icon style |
| **Updates** | Only shows **Updates are provided by Microsoft Store** |
| **Advanced** | Thread count; temporary folder; log level; custom 7z.dll under the LGPL |

## File associations in the Store build

Open **Windows Settings → Apps → Default apps** to choose GenZip for each format. Windows does not let apps make themselves the default.

## Updates in the Store build

Microsoft Store provides updates. GenZip's **Updates** page has no channel selection or update check button.
