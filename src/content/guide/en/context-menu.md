## Microsoft Store integration

File associations and the right-click menu are included in the Microsoft Store package. The **Integration** settings page says **Managed by Windows for the Microsoft Store build**.

## Windows 11 commands

GenZip provides these commands in the top-level Windows 11 right-click menu:

- **Open with GenZip**
- **Extract files…**
- **Extract here**
- **Extract to "&lt;name&gt;\\"**
- **Add to archive…**
- **Add to "&lt;name&gt;.zip"**
- **Add to "&lt;name&gt;.7z"**

**Extract files…** opens the destination and extraction options dialog. **Extract here** uses the archive's location; **Extract to "&lt;name&gt;\\"** uses a folder named after the archive. **Add to archive…** opens the creation dialog; the ZIP/7Z commands perform quick compression.

The classic menu uses **Quick compress to ZIP/7Z** and **Extract to a folder with the same name**.

## Choose the default app

Open **Windows Settings → Apps → Default apps** and choose GenZip for the formats you want to open. Windows does not let apps make themselves the default.

The package registers these formats: `.zip`, `.7z`, `.rar`, `.tar`, `.gz`, `.bz2`, `.xz`, `.zst`, `.iso`, `.cab`, `.wim`, `.001`.
