## Turn it on

**Settings… → Integration** → enable the GenZip context menu. Choose a cascaded menu (one GenZip entry with a submenu) or a flat one.

## Commands

On archives:

- **Extract here**
- **Extract to "Name\\"**
- **Extract files…** (opens the dialog)

On regular files and folders:

- **Add to "Name.zip"**, **Add to "Name.7z"**
- **Add to archive…**

## Windows 11

GenZip appears in the new Windows 11 context menu — no need for "Show more options".

## File associations

In **Integration**, pick the formats GenZip should open. Windows may ask you to confirm the default app. GenZip only writes to your own Windows account.
