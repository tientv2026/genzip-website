## Cài từ Microsoft Store

GenZip được phân phối qua **Microsoft Store**. Dùng trang GenZip trên Store để cài đặt; các bản cập nhật cũng do Microsoft Store cung cấp.

## Lần chạy đầu

1. Mở GenZip từ menu Start.
2. Ở **Trang chủ**, thả tệp nén vào vùng chọn hoặc nhấn để chọn tệp.
3. Dùng **Tạo file nén…** để tạo ZIP, 7Z hoặc TAR, hoặc **Mở file nén…** để duyệt tệp đã có. **Tệp gần đây** giúp mở lại tệp đã dùng.

## Menu chuột phải và ứng dụng mặc định

Menu chuột phải và liên kết tệp có sẵn trong gói Store. Trang **Tuỳ chọn → Cài đặt… → Tích hợp** ghi **Windows quản lý cho bản Microsoft Store**.

Để chọn GenZip làm ứng dụng mở tệp mặc định, vào **Cài đặt Windows → Ứng dụng → Ứng dụng mặc định**. Windows không cho ứng dụng tự đặt mình làm mặc định.

Xem các lệnh trong [hướng dẫn menu chuột phải](/guide/context-menu).
