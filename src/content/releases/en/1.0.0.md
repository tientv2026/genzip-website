## What's in this release

- Opens RAR4/RAR5, ZIP, 7z, TAR, GZ, BZ2, XZ, ZST, ISO, CAB, WIM and split archives.
- Creates ZIP, 7z, TAR with presets, split volumes and AES-256 passwords.
- Safe extraction, archive testing, real pause and background mode.
- Windows 10/11 right-click menu and file associations.
- Light/dark theme, 9 accent colors, Vietnamese and English.
- Signed automatic update checks.
