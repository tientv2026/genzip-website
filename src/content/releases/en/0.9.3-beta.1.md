---
title: GenZip 0.9.3 beta
summary: A bug-fix update for the Microsoft Store beta, combining 0.9.1 to 0.9.3. Released on Microsoft Store on November 4, 2026; existing installs update automatically.
---

## Fixes

- **Right-click menu in the right language:** the Store build always showed English commands; it now follows the language you choose in GenZip.
- **Doing several things at once:** opening or extracting another file while compressing now runs in its own window instead of getting stuck. A file already being processed in another window shows a clear message.
- **Password and "file already exists" prompts** from right-click extraction no longer appear twice, and Vietnamese titles show all diacritics.
- **Taskbar:** the progress bar clears when the job is done, and the GenZip icon no longer has a colored background.
- The Settings and Terms windows now show the GenZip icon in the title bar.
