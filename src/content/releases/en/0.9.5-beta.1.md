---
title: GenZip 0.9.5 beta
summary: A new look, nested archives opened right inside GenZip, right-click commands that close when done, plus many fixes and security improvements. Submitted to Microsoft Store on November 13, 2026; existing installs update automatically once Microsoft approves it.
---

## New look

- **The whole interface has been redesigned:** more compact, new icons, dialogs sized to their content.
- **A tidier progress window:** the destination is shown next to the file name.
- Archives in the file list now show the GenZip icon.

## Features

- **Open an archive inside another archive** right in GenZip, several levels deep, without extracting it first.
- **Right-click commands close when done:** Extract here, Extract to folder, quick compress… a result is shown only on errors or warnings.
- **A button that opens Windows Default apps** so you can choose GenZip for archives.

## Fixes

- ZIP files downloaded from Google Drive with folder names ending in a space now extract correctly.
- Incomplete or truncated archives are clearly reported as incomplete instead of successful.
- No more flicker when windows open; dialogs no longer resize themselves; the progress window no longer cuts off its buttons.
- The password prompt shows only the file name.

## Security and speed

- Blocks file names that disguise their real extension, for example an .exe posing as an image.
- Passwords are cleared from the interface as soon as the dialog closes.
- Archive parsing runs in a more tightly restricted process.
- Sorting, searching and filtering are much faster for archives with tens of thousands of entries.
