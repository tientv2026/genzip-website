## What's in this release

- Open and extract ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ZST, ISO, CAB, WIM and multi-volume archives.
- Create ZIP, 7Z and TAR archives with compression level, method, dictionary, solid mode, volumes and AES-256 encryption (including encrypted file names for 7Z).
- Edit open archives: add, delete and rename items; drag and drop files into the window.
- Create self-extracting .exe archives (7Z format).
- Preview images and text inside archives.
- Integrity test with exportable report.
- Task queue, pause, background mode and taskbar progress.
- File Explorer context menu: extract here, extract to folder, quick compress to ZIP/7Z.
- Favorites, recent files, light/dark theme, accent colors, English and Vietnamese.
- Safe extraction: blocks dangerous paths, preserves Mark of the Web and warns before opening files that can run code.
